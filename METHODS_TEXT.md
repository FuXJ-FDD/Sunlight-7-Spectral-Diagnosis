## Cluster analysis wording aligned with the code

We performed an unsupervised probabilistic clustering analysis to examine whether countries group into recurrent archetypes based on their seven-dimensional national SDG spectra. Before clustering, each dimension was standardized across countries to zero mean and unit variance, placing the dimensions on comparable statistical scales while preserving both cross-national performance differences and internal spectral configurations. Gaussian Mixture Models with spherical covariance structures were fitted for K = 2–10 using Python 3.13.5 and scikit-learn 1.8.0. Model diagnostics included the Bayesian Information Criterion, posterior classification probabilities, and the interpretability and parsimony of the resulting profiles. The main analysis reports a four-archetype solution fitted with 50 initializations and a fixed random seed of 42. Countries were assigned to the component with the highest posterior probability; classification uncertainty was calculated as one minus this probability. Component labels were assigned by interpreting their mean seven-dimensional spectral profiles.
